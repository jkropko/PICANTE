# --- Why all eleven, rather than the first ------------------------------
#
# The listing paginates at 10 per page, so one snapshot documents 10 records.
# Page 1's header showing '102 results' is third-party evidence of the frame's
# SIZE, but only the full set archives the MEMBERSHIP.
#
# That matters more for this frame than for most. ffwd.org is ungated, so
# anyone can re-fetch the listing — but the portfolio GROWS: the 2027
# Accelerator was taking applications on the capture date, and each cohort adds
# roughly ten organizations. A re-fetch in six months returns the frame as it
# stands then, not as it stood at the freeze. These snapshots are the only
# independent route back to the freeze state.
#
# With them, a reader who doubts the captured membership can reconstruct it
# from a third party rather than taking the project's own files on trust.

# --- Note on the page 8/9 timestamps ------------------------------------
#
# Page 9 (074645) carries an earlier timestamp than page 8 (074702). The saves
# were requested in order; the Internet Archive completed them out of order,
# which it does when a request queues. Recorded so the 17-second inversion
# reads as a queueing artifact rather than as evidence the pages were captured
# from different states of the site. All eleven fall within a ten-minute
# window and the record counts across them sum to 102, matching the site's own
# reported total.
